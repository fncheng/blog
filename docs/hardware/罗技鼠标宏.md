## 语法

```lua
PressKey("lalt") 按下按键
ReleaseKey("lalt") 松开按键
PressMouseButton(1) 按下鼠标左键
ReleaseMouseButton(1) 松开鼠标左键
--鼠标右键则是1
```

### 支持的常用键名（注意大小写和写法）

| 按键          | Lua 名称                              |
| ------------- | ------------------------------------- |
| `Alt`         | `"lalt"` / `"ralt"`                   |
| `Ctrl`        | `"lctrl"` / `"rctrl"`                 |
| `Shift`       | `"lshift"` / `"rshift"`               |
| `Enter`       | `"enter"`                             |
| `Tab`         | `"tab"`                               |
| `Esc`         | `"escape"`                            |
| `数字键`      | `"1"` 到 `"0"`（字符串）              |
| `字母键`      | `"a"` 到 `"z"`（字符串）              |
| `F1` 到 `F12` | `"f1"` 到 `"f12"`                     |
| `方向键`      | `"up"`, `"down"`, `"left"`, `"right"` |
| `空格`        | `"spacebar"`                          |


最简单的：
按下并松开鼠标右键后，自动按下并松开左alt键

```lua
function OnEvent(event, arg)
    OutputLogMessage("Event: "..event.." Arg: "..arg.."\n")
    -- 检查是否是鼠标右键释放（默认右键是按钮 2）
    if event == "MOUSE_BUTTON_RELEASED" and arg == 2 then
        -- 模拟鼠标左键按下和释放（默认左键是按钮 1）
        PressMouseButton(1)
        PressKey("lalt") 
        Sleep(50) -- 延迟 50 毫秒，模拟真实点击
        ReleaseKey("lalt")
        ReleaseMouseButton(1)
    end
      
end
```

### 常见鼠标事件

| 事件名                  | 说明                       |
| ----------------------- | -------------------------- |
| `MOUSE_BUTTON_PRESSED`  | 鼠标按键 **按下**          |
| `MOUSE_BUTTON_RELEASED` | 鼠标按键 **松开**          |
| `MOUSE_MOVED`           | 鼠标移动                   |
| `MOUSE_WHEEL`           | 鼠标滚轮滚动（向上或向下） |

### 键盘事件

| 事件名                    | 说明         |
| ------------------------- | ------------ |
| `"KEYBOARD_KEY_PRESSED"`  | 键盘按下事件 |
| `"KEYBOARD_KEY_RELEASED"` | 键盘松开事件 |
